# Diccionario de datos de `db_test`

Documentación derivada de `Respaldo 29-10-26 (corregido).sql` (MySQL 8.0.42). Se procesaron definiciones DDL y se contaron las filas de los `INSERT`; no se incluyen datos.

## Archivos

- [diccionario_datos.md](diccionario_datos.md): documento principal con tablas, columnas, vistas, triggers, rutinas y observaciones.
- [diccionario_datos.xlsx](diccionario_datos.xlsx): hojas Resumen, Tablas, Columnas, Relaciones, Vistas, Triggers, Rutinas.
- [diagrama_er.mmd](diagrama_er.mmd): modelo entidad-relación en Mermaid `erDiagram`.
- [schema.dbml](schema.dbml): esquema DBML.

## Resumen ejecutivo

El DDL contiene 25 tablas, 25 vistas, 72 triggers, 10 procedimientos y 5 funciones. Se regenera con `Practica03/scripts/generar_diccionario.py`.
