# Regeneración

Requisitos: Python 3.10 o superior. No requiere paquetes externos.

Desde la carpeta `Practica03`, ejecute:

```powershell
python .\diccionario_datos\generar_diccionario.py
```

El script lee únicamente DDL del dump ubicado en `backups/Respaldo 20-10-26.sql`, ignora INSERT y regenera los archivos de esta carpeta.
